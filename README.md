# 계산형 GitHub 숙지통계·정렬 완성본

## 적용 기능
- 숙지 버튼: 해당 문항을 숙지로 저장
- 미숙지 버튼: 해당 문항을 미숙지로 저장
- 정답 채점: 숙지로 자동 저장
- 부분정답/오답 채점: 미숙지와 오답으로 자동 저장
- 숙지, 미숙지, 오답 카운트 실시간 갱신
- 숙지율은 `숙지 ÷ (숙지 + 미숙지)` 기준으로 계산
- 전체 / 숙지 / 미숙지 / 오답 / 복습예정 필터
- 챕터 선택 및 검색과 학습상태 필터를 동시에 적용
- 새로고침하거나 브라우저를 닫아도 기록 유지

요청하지 않은 랜덤시험·별도 진도율 기능은 추가하지 않았습니다.
